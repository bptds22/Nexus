# Journal des sessions

Un fichier par jour : `AAAA-MM-JJ.md`. Une section par chantier.
Écrit par le skill `journal-session` ; lu par le tableau de bord du matin.
Ne pas changer les libellés (« État : », « Fait : »…) : le tableau de bord les lit tels quels.

## Modèle

```markdown
# Journal — AAAA-MM-JJ

## <nom du chantier>
- État : En cours | À tester | Prêt | Bloqué | Fait
- Fait : …
- Reste : …
- Décisions de BP : aucune
- Migrations : aucune
- Branche : …
```

Loi 25 : aucun nom, courriel, téléphone ni UUID de personne.
