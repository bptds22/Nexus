# Lot D3 — textes Loi 25 à valider par BP (brouillons, rien n'est publié)

Décision BP 2026-10-28 (Q6), revue après l'annulation de Q8 : les recruteurs universitaires validés voient les profils
de TOUS les athlètes (secondaire, civil, cégep, sans établissement), comme les recruteurs collégiaux, plus les
cégépiens. Avis et ligne de politique AVANT de passer `lancement_universitaire` à ON ; textes tranchés à ce moment.

## 1. Avis aux athlètes (dans l'app, et par courriel si BP le veut)

**Titre :** Les recruteurs universitaires arrivent sur Nexus

**Texte :**
À partir du [date], les recruteurs universitaires inscrits sur Nexus pourront voir ton profil d'athlète, comme les
recruteurs collégiaux le font déjà. Chaque compte de recruteur universitaire est validé par l'équipe Nexus avant
d'avoir accès aux profils.

Ce qu'ils verront : les mêmes renseignements que ton profil montre déjà aux recruteurs, selon tes réglages de
visibilité.

Tu gardes le contrôle : tu peux changer ce qui est visible à tout moment dans **Visibilité**.

[Bouton] Voir mes réglages de visibilité

## 2. Ligne pour la politique de confidentialité (section « Qui peut voir tes renseignements »)

> Les recruteurs universitaires inscrits sur Nexus, après validation de leur compte par notre équipe, peuvent voir
> les profils de tous les athlètes, comme les recruteurs collégiaux, y compris ceux des athlètes rattachés à un
> cégep.
