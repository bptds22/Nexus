# Sorare

## Pourquoi cette app

Sorare est la référence pour la "carte joueur" digitale collectionnable — le profil athlète Nexus a un format de carte similaire (cf. AthletePlayerCard.tsx). À étudier pour le rendu visuel d'un athlète, la marketplace, et l'animation des cartes.

## Patterns à reprendre

- Carte joueur format vertical avec photo + nom + stats clés
- Animations de rareté (gradient, glow, hover)
- Tap sur une carte = profil détaillé

## Patterns à éviter

- Marketplace complexe avec enchères et prix dynamiques — pas le scope Nexus
- Surcouches gamification (tournaments, leaderboards) — Nexus est sérieux/pro
