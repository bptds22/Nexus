# NHL

## Pourquoi cette app

L'app NHL officielle est la référence du profil joueur pro de haut niveau : photo studio, mensurations détaillées, stats avancées, comparaisons. Utile pour la qualité visuelle attendue d'un profil athlète Nexus version "all star".

## Patterns à reprendre

- Hero photo studio du joueur (large, presque pleine largeur)
- Mensurations bien hiérarchisées (taille / poids / âge avec icônes)
- Stats tabulaires avec colonnes lisibles sur mobile
- Comparaisons "vs équipe" / "vs ligue" avec barres horizontales
- Sticky tab nav (Bio / Stats / Game log / etc.)

## Patterns à éviter

- Données trop denses (NHL = ligue pro, athlètes secondaires Nexus ont moins de données)
- Replay vidéo intégré — Nexus reste sur YouTube/Hudl externes
- Score tracking live — pas applicable
