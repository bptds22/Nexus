# Strava

## Pourquoi cette app

Strava est LA référence pour le profil athlète et le feed d'activité côté athlète. Données quantitatives bien présentées, courbes de progression, badges. Directement applicable au dashboard athlète + profil athlète Nexus.

## Patterns à reprendre

- Stats personnelles en gros chiffres (km, vitesse) → équivalent : tests physiques athlète
- Feed d'activité chronologique avec cards
- Graphes de progression simples, lisibles sur mobile
- Profil athlète avec photo de couverture + photo de profil + stats clés

## Patterns à éviter

- Social network features (kudos, comments) — Nexus est focus recrutement, pas social
- Carte / itinéraire GPS — pas applicable
- Premium upsell intrusif
