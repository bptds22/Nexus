# LinkedIn Recruiter

## Pourquoi cette app

LinkedIn Recruiter est LA référence pour le côté recruteur : pipeline candidats, recherche avancée avec filtres complexes, messaging in-app, notes privées. Transposable directement sur le portail recruteur Nexus (recherche, pipeline, favoris, messages).

## Patterns à reprendre

- Recherche avec filtres en sheet bottom (mobile) ou drawer (desktop)
- Cards candidats compactes : photo + nom + 2-3 stats clés + action
- Pipeline en colonnes scrollables horizontalement OU en filtre par stage
- Notes privées sur un candidat (visible uniquement par le recruteur)
- Messaging in-app avec preview message + sujet
- Indicateurs visuels (vu / pas vu, déjà contacté, etc.)

## Patterns à éviter

- Premium upsell omniprésent
- Suggestions automatiques d'IA mal calibrées
- "Stories" ou contenu social — pas adapté
