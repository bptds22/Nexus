# Apps observées — index par pertinence Nexus

Liste ordonnée des apps mobiles dont on capture des écrans, du plus pertinent au moins pertinent pour le portage mobile Nexus.

| App | Dossier | Pertinence pour Nexus |
|---|---|---|
| **Sorare** | [sorare/](sorare/) | Profil joueur, carte digitale (player card), marketplace — directement transposable sur les profils athlètes Nexus. |
| **Strava** | [strava/](strava/) | Profil athlète, feed d'activité, stats personnelles, courbes de progression — pertinent pour le dashboard athlète et son profil. |
| **NHL** | [nhl/](nhl/) | Profil joueur pro (mensurations, stats avancées, photos pro), comparaisons — référence pour la qualité d'un profil sportif. |
| **LinkedIn Recruiter** | [linkedin-recruiter/](linkedin-recruiter/) | Pipeline candidats, messaging, recherche avancée avec filtres — directement transposable côté recruteur. |
| **Trello (mobile)** | [trello-mobile/](trello-mobile/) | Kanban mobile — critique pour refondre `/recruteur/pipeline` (la page identifiée comme cassée dans l'audit visuel). |

## Ajout d'une nouvelle app

1. Créer le sous-dossier kebab-case
2. Créer `notes.md` minimum avec le template (voir README.md)
3. Ajouter une ligne dans le tableau ci-dessus avec pertinence pour Nexus
